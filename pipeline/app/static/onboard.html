Job Search — Setup

Checking your repository…

    Your resume

    Upload your resume as a PDF. We extract the text for keyword scoring and the cloud evaluator — it never leaves your machine except as an encrypted GitHub secret. We'll also auto-fill the About step from it.

    About you

    Work authorization (optional — filters roles you can't take & answers screening questions)

    Country-neutral: describe your eligibility. A US citizen eyeing roles in the EU and an EU citizen eyeing the US fill this in the same way.

    Voluntary self-identification (optional — auto-answers EEO questions)

    Leave any field blank to decline ("prefer not to say") on every application — the default. Fill one in only to self-identify; it's matched against the form's options, so use the employer's wording.

    Some job sites ask you to consent to processing your self-identification data, and to save or share those answers, before an application can be submitted. You provide none either way, but the consent is required on the sites that ask for it.

    Roles & compensation

    Search settings

    Put "Remote" in a chunk to route that pass through JobSpy's remote filter. Examples: Dallas, TX · London, UK.

    Job boards

    Career narrative (optional — improves evaluations)

    AI evaluation provider

    Pick a provider and paste its API key. The key is written straight to a GitHub secret (via stdin) and never logged or stored locally.

    Local evaluation provider

    Configures which provider the UI uses for + Add Job evaluations and the API path for career skills. Saved to your local .env — separate from the GitHub secrets above. You can skip this step and configure it later.

    Detecting…

    When on, evaluation and résumé tailoring stay within the free-tier RPM/RPD (e.g. ~20 jobs/day on gemini-2.5-flash; the rest defer to the next run). Use gemma-4-26b-a4b-it for ~1,500/day.

    Auto-apply: off-site ATS account (optional)

    For the agentic apply engine to sign into / create accounts on employer ATS (Greenhouse, Lever, Workday, …) and auto-read email verification codes. Local only — written to .env, never uploaded to GitHub. Leave a password blank to keep the one already saved.

    Auto-apply (optional — local only)

    Auto-apply fills and submits applications from your own machine (never in the cloud). Choose the platforms to auto-apply on — each needs a one-time sign-in so the local browser carries your session. A window opens for you to log in; the session is saved for later.

    Review & submit

    This generates your profile, CV, and search config, then writes them — plus your API key — as encrypted GitHub secrets on your repo. We refuse to write to a public repo.
